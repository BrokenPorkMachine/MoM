# VolumeBoot v0.4.0 — Restore-image provisioning

Adds local IPSW selection, compatible hardware identification, new VM creation, sparse disk image, persistent virtual identity, macOS installer orchestration, manifest and UI integration.

**Not implemented:** direct boot of arbitrary physical macOS installations, privileged physical disk access, PCIe passthrough, or generic USB passthrough. These remain experimental.

**Build confidence:** Linux Swift syntax parsing and project consistency only. Full macOS SDK type checking, Xcode compile and real provisioning require a Mac.

See VM_PROVISIONING.md, SECURITY.md and VM_RUNTIME.md.
